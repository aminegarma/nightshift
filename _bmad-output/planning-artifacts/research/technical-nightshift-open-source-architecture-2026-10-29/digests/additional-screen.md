# Additional integrated-stack screen

Retrieved official sources 2026-10-29. Medium confidence for documented features/licences; integration fit is inference; resource/scalability not benchmarked.

- Zabbix AGPLv3 since 7.0: https://www.zabbix.com/license . Support lifecycle and currently supported branches: https://www.zabbix.com/life_cycle_and_release_policy . Proxy stores and forwards metrics and supports IPMI/SNMP, but does not calculate triggers, process events or send alerts: https://www.zabbix.com/documentation/current/en/manual/distributed_monitoring/proxies . Implication: a proxy alone does not provide local autonomous decisioning. Existing Zabbix is a valuable hardware/network source; full local server/database adds overhead. Repo https://github.com/zabbix/zabbix . Exact patch/advisory clearance not verified.
- Netdata OSS Agent GPLv3+; current repository explicitly marks UI/Cloud as closed-source: https://github.com/netdata/netdata . Release page https://github.com/netdata/netdata/releases includes v2.12.0 September 30 publication label, new Redfish sensor collector, early-access OTel tracing and host platform caveats. Strong consolidation wildcard for observation/ML benchmark; not blanket OSS edition, established new-feature maturity or disconnected UI guarantee. No resource comparison verified.
- Rancher Fleet Apache-2.0 https://github.com/rancher/fleet ; GitOps YAML/Helm/Kustomize converted to Helm deployments documented at https://fleet.rancher.io/ . Release page https://github.com/rancher/fleet/releases retrieved; README quickstart uses v0.16.3, but that is not an assertion of current latest stable. Alternative if existing Rancher/Fleet already operates; isolated patching, credentials, privileges, offline cold recovery and capacity need validation.
