# Fleet, policy and platform evidence

Accessed 2026-10-29; publishers are respective maintainers. Undated living docs unless noted. Confidence: medium, primary-source supported; independent production/10,000-cluster validation absent.

| Tool / finding | Evidence | Limitation / recommendation |
|---|---|---|
| Flux, Apache-2.0; per-cluster Git/OCI reconciliation; OCI signature verification supported | https://github.com/fluxcd/flux2 ; https://fluxcd.io/flux/components/source/ocirepositories/ | MVP local pull deployment. Cache artifacts/images for outages; last applied state does not ensure cold recovery without dependencies. |
| Flux multi-tenancy needs explicit lockdown, service-account impersonation and network policy | https://fluxcd.io/flux/security/best-practices/ | Do not mistake installation defaults for tenant isolation. Dedicated workload clusters reduce one boundary, central fleet still multi-tenant. |
| Argo CD, Apache-2.0; documented HA/sharding tuning | https://github.com/argoproj/argo-cd ; https://argo-cd.readthedocs.io/en/stable/operator-manual/high_availability/ | Viable alternative when already deployed; central remote reconciliation isn't the local repair loop. |
| OCM, Apache-2.0; hub/klusterlet pull model, double opt-in, per-cluster namespaces | https://github.com/open-cluster-management-io/ocm ; https://open-cluster-management.io/docs/concepts/architecture/ | Enterprise fleet inventory/placement candidate. Documentation's thousands-of-clusters discussion is architecture guidance, not independently reproduced 10k benchmark. Old registration-operator repo archived/moved: use consolidated ocm. |
| OPA, Apache-2.0, embeddable Go SDK; auth off by default on standalone server | https://github.com/open-policy-agent/opa ; https://www.openpolicyagent.org/docs/security | Embed policy evaluation in executor to avoid extra unauthenticated service. Policy does not provide workflow, approvals or precondition truth. |
| Cedar, Apache-2.0; explicit forbid overrides permit; default deny | https://github.com/cedar-policy/cedar ; https://docs.cedarpolicy.com/auth/authorization.html | Strong alternative for principal/action/resource authorization, additional integration work for Go. |
| NATS server, Apache-2.0; JetStream persistence; outbound leaf topology; account isolation | https://github.com/nats-io/nats-server ; https://docs.nats.io/concepts/jetstream ; https://docs.nats.io/learn/topologies/leaf-nodes ; https://docs.nats.io/learn/security/accounts-and-multitenancy | Optional enterprise event bus. At-least-once replay requires executor idempotency; leaf connectivity alone isn't durable replication. |
| SQLite public-domain core; embedded local store; PostgreSQL PostgreSQL licence; RLS supported with owner/superuser bypass caveats | https://www.sqlite.org/copyright.html ; https://www.sqlite.org/whentouse.html ; https://www.postgresql.org/about/licence/ ; https://www.postgresql.org/docs/current/ddl-rowsecurity.html | SQLite PoC single writer, CRD/controller status for cluster HA, PostgreSQL central metadata. Never hold a shared SQLite file across replicas. |
| Keycloak and Dex Apache-2.0 | https://github.com/keycloak/keycloak ; https://github.com/dexidp/dex | Reuse existing Quornex identity first; Keycloak full IAM, Dex federation. Neither grants repair approval semantics automatically. |
| SPIRE Apache-2.0; workload attestation/identities; OpenBao MPL-2.0; cert-manager Apache-2.0; SOPS MPL-2.0 | https://github.com/spiffe/spire ; https://github.com/openbao/openbao ; https://github.com/cert-manager/cert-manager ; https://github.com/getsops/sops | Existing local PKI/secrets first. Enterprise workload identity and secrets service if justified; never make local repair require central token refresh during outage. |
| Alertmanager Apache-2.0 routing; Gotify MIT push; ntfy dual Apache-2.0/GPLv2 | https://github.com/prometheus/alertmanager ; https://github.com/gotify/server ; https://github.com/binwiederhier/ntfy | Routing/push are not approval verification or guaranteed phone delivery. Critical phone integration incurs carrier/provider costs. |
