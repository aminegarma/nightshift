Nightshift colour themes: round 1 (5 variations)

Each variation is shown in light and dark side by side. Brand-neutral: tokens will be mapped onto Quornex’s design system later. Only shades, neutrals, surfaces and the accent change; the meaning of each hue is fixed:

  • red = Critical / Failed / Dangerous · orange = Warning / Needs attention / Risky · blue = Informational / Running / Verifying / Being watched, and primary buttons
  • violet = waiting for a person · green = Succeeded / Resolved / Safe, and Verified facts · yellow = Nightshift’s explanation (written by AI) · grey = Rejected / Blocked / Cancelled / Expired, and no data / stale data (grey + diagonal hatching, always labelled)

Every ratio printed is the WCAG 2.x contrast of the pair named next to it (target 4.5:1 for text; 3:1 for borders and focus rings, which are non-text). Hex values for every token are in a comment block per variation inside the <style> element.
